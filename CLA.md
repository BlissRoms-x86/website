## 3. How individuals sign on GitHub

On a pull request, the CLA check will ask you to comment:

```text
I have read the CLA Document and I hereby sign the CLA
```

That comment is your acceptance of section 1 (ICLA). Read this file first. Corporate contributors still send section 2 to contact@blisslabs.org.
