Infrastructure

We need build machines as well as code

AOSP-on-PC does not compile on a laptop in the background. If we want community nightlies and a download pipeline again, we need build capacity, storage, bandwidth, and hardware to test on. Money helps. So do unused servers and disk.

What we need

Build

Compile machines

High-core x86_64 hosts with large RAM and fast disk for AOSP and kernel builds. Persistent self-hosted GitHub Actions / CI runners beat bursting cloud credits on this class of project.

  • Community nightly builders
  • Dedicated kernel / Mesa builders
  • Access we can document for trusted contributors
Ship

Storage, CDN, mirrors

ISOs and debug artifacts are large. SourceForge archives cannot replace a release pipeline. We need disk and bandwidth under BlissLabs control, plus volunteer mirrors.

  • Object storage or dedicated download hosts
  • Geographic mirrors
  • Retention for a small set of nightlies
Test

Hardware

Laptops, Surface-class devices, mini-PCs, ARM boards, kiosk/TV gear. The Device Seeding Program exists specifically to buy or receive this.

  • UEFI PCs for installer and desktop testing
  • SBCs and ARM targets used by Bass / AG
  • Spare NVMe / RAM for builders
Fund

Recurring costs

Power, transit, domain, and the occasional cloud burst. Fiscal host is BlissLabs via Open Collective. That ledger is public.

  • Labeled gifts for infra vs devices vs R&D
  • Company sponsorship with a logo if you want it
  • One-time hardware grants

Three levels of help

Mirror or host

Offer rsync/HTTP space for ISOs and source snapshots. Email us with capacity, region, and how long you can keep it.

Lend a runner

A machine we can SSH to or register as a self-hosted runner. Tell us cores, RAM, disk, and whether it can stay on 24/7.

Sponsor a month of builds

Underwrite power, storage, or a cloud builder for 30 days. We will credit sponsors on this page when you want that.

In-kind offers: write contact@blissos.org with subject "Infrastructure offer". Hardware shipping and device loans: same address, or the Device Seeding collective. We will not publish your street address. We will credit the donation if you want credit.
