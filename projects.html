Ecosystem

Projects

Bliss OS is a family of repositories. This map is the shortest way to find the org that matches the work you want to do.

How the pieces fit

Android-Generic and the kernel trees are the bring-up layer. BlissOS / BlissRoms-x86 is the OS people install. The desktop you click on is a separate layer: Boringdroid (freeform windows and taskbar in AOSP), Smart Dock (launcher), and XTMapper (keyboard and mouse mapping). Ānanda Āropa is the new installer and initrd. Bass editions use audio names (Lineout, Submix) as a play on BASS, Broad Apparatus Support System: Lineout is a FOSS Lineage OS tree for x86_64; Submix is Debian plus Waydroid. Bliss-Bass ships this stack on devices and contributes selected work back when it helps the whole ecosystem.

Apps and desktop components

These are BlissLabs projects in the application layer: window management, the desktop launcher, and input mapping. They are developed as their own repos (often without a full AOSP tree) and shipped or used with Bliss OS. If you write Android apps, this is usually a better first patch than frameworks.

Windows / SystemUI

Boringdroid

Minimal AOSP patchset for freeform multi-window by default: minimize and resize, plus a PC-style taskbar (running tasks and installed apps). BlissLabs project, tracked as small forward-portable patches rather than a fork of the whole OS.

boringdroid.github.io
github.com/boringdroid

Launcher

Smart Dock

Desktop-mode launcher: dock, app menu, keyboard shortcuts, tablet and desktop layouts, multi-window. Independent app (axel358), featured under BlissLabs and used as the Bliss OS desktop shell. Java/Kotlin; no AOSP clone required.

github.com/axel358/smartdock

XTMapper

How the work flows both ways

Bliss OS is the public project. Navotpala Tech is the commercial counterpart that works with this community. Users and FOSS developers stay here. Companies that need a contract, a license, or someone to stand behind a product start there. The two are meant to feed each other.

Community

Bliss OS

People write code, docs, and tests in the open. That public development is what the OS is made of, and it is what Navotpala Tech builds on when a company needs help.

Commercial

Navotpala Tech

Contract development with this community, plus commercial licensing, LTS, servicing, and liability for Bliss OS, Bass OS, Waydroid, and related stacks. If you want to ship a product, that is the door.

Commercial

Bliss-Bass / Bass OS

If you want to ship this stack on a device, brand an image, or talk about a license, Bass OS is Navotpala Tech's commercial distro. Demos and licensing live there. This page stays about Bliss OS and the public trees next to it.

BASS is Broad Apparatus Support System. Editions use audio names (Lineout, Submix, and others) as a play on that acronym. Shared work that helps everyone can land in the commons and help Bliss; product-only extras stay on Bass. Public trees for those editions are below.

Android 16 FOSS Contribution

Bass: Lineout Core

Lineage OS for x86_64 used as the base for Bass: Lineout builds: tablet, desktop, TV, and auto. Source is in los-tv-x86, including the Mesa fork used in current BlissOS and Android-Generic builds.

A public Android 14 Bass fork, lineage_bass_android, expands that Lineage tree for tablet, desktop, and related targets. It is a Bass snapshot, not the original TV-x86 project, and Bliss OS does not treat it as an upstream we expect someone else to maintain.

The original Android 14 TV-x86 effort is an independent personal project at LineageOS-TV-x86. Do not file Bliss OS or Bass issues there. That maintainer is not responsible for updates, support, or patches from this site.

Lineout Core (los-tv-x86) · A14 Bass fork

Android 16 Debian + Waydroid FOSS Contribution

Bass: Submix

A Debian host that boots a Wayland compositor (Cage by default, with Weston or X11 as fallbacks) and runs Lineage OS 23 / Android 16 inside a Waydroid LXC container. Linux owns the display, input, and network. Android is the guest, so you get a near-native Android session on generic x86_64 without Bliss OS's Android-on-bare-metal boot.

Source is in bass-submix: Debian rootfs and initrd, live USB plus a Control Panel installer, GRUB / host / Android overrides, and the Waydroid session. If you want Linux as the host and Android as the contained OS for a device image, this is the Bass edition to look at. Demos and licensing live on the Bass site.

Submix is not a Bliss OS desktop ISO, and it is more than stock Waydroid on a random distro. Shared host, installer, and graphics work can help the whole stack. Product-only extras stay on Bass, so Bliss can stay the FOSS OS people install.
