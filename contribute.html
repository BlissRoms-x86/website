Contributors

How to contribute

Don't wait for a release announcement. Send patches, docs, hardware reports, and review. If you have machines to lend instead of time, see the infrastructure page.

Join Matrix Dev Telegram Code of Conduct CLA

Development chat is open. General user support is not the current focus. Use Matrix (#blissos:matrix.org) or the development Telegram (t.me/androidgenericpc). Do not expect those rooms to replace docs or to staff end-user help for archived ISOs.

Ways to help

Platform / AOSP

Manifests, frameworks, bionic, ART, device/generic trees. Heavy clone, heavy RAM. Introduce yourself on Matrix or the development Telegram before a huge PR.

BlissOS · BlissRoms-x86

Kernels & graphics

Zenith and other AG kernels, Linux driver bring-up, Mesa. Graphics work currently includes the fork used by new BlissOS and AG builds, in android-generic.

kernel-zenith · external_mesa

Installer / Linux

Ānanda Āropa: Calamares modules, rootfs, GRUB, initrd scripts. Smaller than AOSP and a realistic first contribution.

Ananda-Aropa · bootable_aaropa

Apps & desktop components

Android app and SystemUI work that does not need a full platform clone: Boringdroid (freeform / taskbar), Smart Dock (desktop launcher), XTMapper (keymapper). A realistic first contribution if you write Java or Kotlin. New apps and components can be proposed the same way.

boringdroid · Smart Dock · XTMapper · Propose one

Bass: Lineout Core

Bass-funded Lineage OS tree for x86_64, and the base for Bass: Lineout builds (tablet, desktop, TV, and auto). Android 16 in los-tv-x86. The public Android 14 Bass fork is reference source only; do not treat the original TV-x86 personal project as a Bliss OS maintenance target.

los-tv-x86 · Lineout notes

Bass: Submix

Lightweight Debian host, Wayland compositor, Lineage OS / Android in a Waydroid LXC container. Near-native Android on generic x86_64, with extra Bliss-Bass device customization. Debian, compositor, and container work; not a full AOSP tree.

bass-submix

Android-Generic tooling

AG vendor project, AGPM, docs, and prototyping scripts. Useful if you like build systems more than framework Java.

android-generic · AG site

Docs & testing

Rewrite install, config, and FAQ pages against the new tree. Test on VMs (VirtualBox, QEMU/VirtIO) and real PCs. File hardware reports with logs, not just "it doesn't boot."

docs.blissos.org · bug_reports

Design, web, community

Screenshots, installer UX, this website, triage, and moderation. Product strategy help is welcome if you can work with the rest of the team.

website repo

How to start

  1. Read the Code of Conduct and the Contributor License Agreement. Join Matrix or the development Telegram. Say what you can build and what hardware you have. Original patches need a signed CLA before merge; company work also needs a Corporate CLA emailed to contact@blisslabs.org.
  2. Skim the project map and pick one org, not all of them.
  3. If you have never built AOSP: start with Smart Dock, XTMapper, Ānanda Āropa, AG docs, or bug_reports. Full platform builds need serious disk and RAM; if you lack that, help us host runners or stick to apps, installer, or docs.
  4. Send a small, complete change: a script fix, a Calamares string, a doc page that matches current behavior, a kernel config note. Huge drive-by refactors are hard to review.
  5. Some BlissROMs history still goes through Gerrit. If a README says Gerrit, use Gerrit. Otherwise GitHub PRs on the repo you cloned.

Authorship and licenses

Keep git history honest. Do not strip authorship from AOSP, Android-x86, Lineage, Mesa, Calamares, or other upstreams. Each repo has its own license. Apache 2.0, GPL, and others all appear in this ecosystem.

If you are contributing on behalf of a company, say so. Shipping this on hardware in a way that cannot comply with those licenses belongs on the licensing page, not in a pull request.

Cannot build locally?

These trees are large. That is normal. You can still write docs, triage bugs, work on Smart Dock, XTMapper, or Aaropa, or lend a runner, disk, or test device.
