As of August 2026

Development status

Public images are paused. Development continues. This is a status page, not a countdown or a "the project is dead" notice.

What the pause is

We stopped publishing new official Bliss OS images while the next tree is built. The previous public tree, documentation, and support notes do not describe what we are building now. Shipping another ISO on top of that would have created a support mess and a false upgrade path.

That decision was never "the project stopped." BlissOS, BlissRoms-x86, Android-Generic, Ānanda Āropa, Bliss-Bass, desktop components (Boringdroid, Smart Dock, XTMapper), and related trees have stayed in active development. We did not keep sending people to old docs and old group FAQ as if they still matched the current tree.

No ETA. We will not invent a ship date for the first public image from the new tree. The remaining blockers are documentation, builders and mirrors, and enough testing that we can actually support what we publish.

What this means for users

  • Older SourceForge builds are archives: no updates, no official support.
  • Existing installs will not OTA or sideload onto the new codebase. A clean install will be required.
  • General Telegram/Discord user support was paused with the public releases.
  • Development chat remains the place to talk about the next tree.

If you want to help close the open items

Code, docs, hardware reports, build machines, and mirrors are all needed before we can ship. Licensing and commercial builds still exist; they live on their own pages now.
